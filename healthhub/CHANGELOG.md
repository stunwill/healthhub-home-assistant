# HealthHub Home Assistant Changelog

## 0.8.1

- Added Daily Diary image and barcode capture entry points.
- Added multi-image local OCR with mandatory nutrition review before saving.
- Added diary-aware barcode lookup and direct Save & Add workflows.
- Preserved existing Food Library, import, planning and FoodHub integration data.

## 0.8.0

- Added the selected-date Daily Diary and weekly planning workflow.
- Added planned versus eaten tracking, reusable saved meals and faster local-first Quick Add.
- Added responsive planner behaviour and authoritative FoodHub recipe planning.

## 0.7.0

- Added CSV/XLSX Food Library import, barcode/product lookup and local nutrition-label OCR.
- Added nutrition provenance, review safeguards and authoritative FoodHub recipe nutrition ingestion.

## 0.6.0

- Added the reusable Food Library, composite foods, profile preferences and spreadsheet paste import.
