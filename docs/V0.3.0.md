# HealthHub v0.3.0 - Exercise, Weight & Progress

## Release goal

Extend the usable v0.2 daily nutrition workflow with manual activity and weight tracking, while keeping HealthHub non-prescriptive and independent from external fitness services.

## Included

- manual exercise logging
- duration and user-supplied exercise calories
- no/full/percentage exercise-credit modes applied to the real daily calorie budget
- manual weight logging in kilograms
- recent weight history
- starting and goal weight context when configured on the profile
- functional Progress screen
- Quick Add shortcuts for Exercise and Weight
- migration and integration tests

## Data model

Migration `0003_exercise_weight` adds:

- `exercise_entries`
- `weight_entries`

Both tables use stable UUIDs, profile foreign keys, UTC-backed timestamps, created/updated timestamps and indexes for profile/time queries.

## Calculation behaviour

HealthHub does not calculate calories burned from activity type, duration, age, weight or other characteristics in v0.3.0. The completed calorie value is entered by the user from a trusted source.

The existing domain calculation then determines credited exercise calories:

- no credit: 0
- full credit: completed exercise calories
- percentage credit: completed calories × configured percentage

Whole-kcal values continue to use half-up rounding in the shared calorie-budget service.

## Safety boundary

- no medical advice
- no automatic calorie target calculation
- no automatic goal-weight calculation
- no public exposure
- no new authentication system
- no wearable or health-platform import

## Deferred

Recommended v0.4.0 scope is weekly food planning and recurrence. Water logging, richer charts, barcode/OCR integrations, wearables, smart scales and broader analytics remain later work.
