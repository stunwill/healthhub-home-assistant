# HealthHub v0.4.0, Planning & Recurrence

## Scope

v0.4.0 turns the Week navigation into a functional personal food-planning workflow without expanding into drag-and-drop planning, hydration, wearable imports or automated FoodHub consumption.

## User workflows

A user can search HealthHub foods, choose a date/time, meal period and serving count, then create either a one-off plan or a simple recurrence rule. The Week view shows planned and consumed calorie totals by day. Planned entries can be marked consumed or skipped.

## Persistence

Alembic revision `0004_planning_recurrence` adds `planned_entries` and `recurrence_rules`. Planned entries snapshot nutrition values at creation time. The existing `/data/healthhub` SQLite database remains the single HealthHub datastore.

## Recurrence semantics

Supported patterns are daily, weekdays and weekly. Creation materialises an eight-week horizon. No recurrence rule automatically records consumption. Archiving a recurrence rule does not erase already-materialised plans.

## FoodHub boundary

FoodHub remains the household recipe and scheduled-dinner source of truth. HealthHub v0.4 does not write to FoodHub schedules and does not query FoodHub's database. FoodHub recipe items without authoritative per-serving nutrition remain non-consumable in HealthHub.

## Deferred

- drag-and-drop week planning
- unscheduled meal tray
- hydration diary
- richer weight charts and analytics
- barcode lookup
- functional OCR/AI nutrition extraction
- wearables and smart scales
