# HealthHub v0.2.0 - Daily Diary & Food Core

## Scope

This release makes the Today experience useful without expanding into exercise, planning or wearable integrations.

### Included

- HealthHub food catalogue with Australian nutrition-label fields
- consumed food diary per profile
- daily calorie and macro totals
- predictive local Quick Add
- graceful FoodHub recipe-search adapter
- nutrition-label image upload and mandatory review workflow
- schema migration `0002_foods_diary`
- Home Assistant `app_config` mapping
- updated container/runtime version handling

### Data behaviour

Diary entries store nutrition snapshots. A later edit or archive of the source food does not rewrite historical consumed totals.

All consumed timestamps are accepted as timezone-aware values, stored as UTC, and selected for a day using the profile's configured timezone.

### Nutrition-label safety

v0.2.0 does not perform OCR or AI extraction. Uploaded images return an `awaiting_review` state with no fabricated extraction result. The review endpoint rejects saves unless the caller explicitly confirms the values were reviewed.

### FoodHub boundary

HealthHub calls only versioned FoodHub interfaces. The recipe search adapter expects `/api/v1/recipes/search` and returns an empty result set if that endpoint is unavailable. HealthHub never reads the FoodHub database and continues to operate normally when FoodHub is offline.

### Deferred

- FoodHub recipe consumption until authoritative per-serving nutrition is available
- barcode lookup
- OCR/AI label extraction
- exercise diary
- weight and progress charts
- water diary
- weekly planning and recurrence
- wearable or smart-scale imports
